# 开发与存档说明

## 运行结构

- `script/realm-core.js`：无 DOM 的建设、人口、产出、研究、领地、公共工程和离线计算。
- `script/realm.js`：接入原版引擎，提供建设面板、布局、难度和设置。
- `script/expedition.js`：文字地图、触屏操作、自动行进、检查点与死亡救援。
- `script/cloud.js`、`auth-key.js`、`save-format.js`：账号、本机存档、密码派生和共用格式校验。
- `worker/index.js`：同源 JSON API；静态资源通过 Workers Static Assets 提供。
- `migrations/0001_accounts.sql`：D1 账号、会话、存档、历史与频率限制。
- `tools/build.mjs`：按允许列表复制游戏资源到 `dist/`，不会发布服务端源码、数据库和测试文件。

原版引擎与资源继续保留，仅去掉启动时一次性预加载全部音频，以及页面的外部分析脚本。扩展主要通过显式包装原版入口接入。默认加载仓库已有的 `lang/zh_cn`；新增内容的简体文本集中在扩展脚本中。

## 部署

`wrangler.jsonc` 配置一个 Worker、静态资源绑定 `ASSETS`、D1 绑定 `DB`。没有硬编码账号 ID、数据库 ID 或共享密码。Wrangler / Deploy to Cloudflare 根据配置创建或连接资源。

`npm run deploy` 顺序为构建、部署 Worker、对绑定 `DB` 执行远程迁移。先部署允许 CLI 首次使用时自动创建数据库；部署按钮流程也可以事先创建资源。首次初始化期间 API 会返回明确的 503 提示。当前迁移仅创建表、索引和触发器，可重复执行；以后涉及表结构变更时，应评估先迁移还是先发布的兼容性。

用户在部署页面重命名数据库时，迁移仍引用绑定名 `DB`。已有线上实例更新时应保留平台生成的数据库绑定配置，避免绑定到一个新库。线上数据不会提交到 Git。GitHub Actions 只使用临时本地 D1，不需要 Cloudflare 密钥，也不负责发布。

## 账号与安全边界

用户名先做 Unicode NFKC 规范化、去除两端空白，再按小写索引；支持 3—32 个文字、数字、下划线或短横线。注册页面要求密码 8—128 位。

为控制 Worker 的认证 CPU 开销，浏览器通过 Web Crypto 执行 PBKDF2-HMAC-SHA256（600,000 次、256 位输出），盐包含固定协议版本和规范化用户名。API 接收这个 **等价于密码的派生凭证**，再使用独立随机 32 字节盐执行 10,000 次 PBKDF2 后存入数据库。服务器不保存原始密码或客户端派生凭证。客户端派生凭证一旦泄漏仍可被用于登录，因此必须通过 HTTPS 传输，也不能写入日志；这不是零知识认证或端到端加密。

会话使用 32 字节随机令牌，数据库只存其 SHA-256；HTTPS 下使用 `__Host-adr_session`、`Secure`、`HttpOnly`、`SameSite=Strict` Cookie，有效期 30 天。localhost HTTP 测试使用无 `__Host-` 前缀的 Cookie。退出撤销当前会话；使用恢复码重设密码会轮换恢复码并撤销全部旧会话。恢复码也是随机 32 字节，数据库仅保存摘要。

写入 API 校验同源 `Origin` 和专用请求头，不开放 CORS；D1 使用参数绑定和用户 ID 查询。IP、用户名与账号写入频率都有数据库限制。存档设置请求大小、字段字符、嵌套深度、节点数、地图结构及关键类型检查，阻止原版动态状态访问受到恶意导入字段影响。游戏状态仍由客户端计算，用户可以修改自己的存档；不提供竞争排行或服务端反作弊。

## 保存与恢复

本机存储使用 `adr:guest` 和 `adr:user:<id>` 隔离。`:meta` 保存云端版本、更新时间和待同步标记；`:before-restore` 是替换前的备份，`:unreadable` 保留无法读取的原始数据。原版 `gameState` 只迁移一次且保留原文件。

云端每个用户一行当前存档。写入必须携带读取时的整数版本；D1 条件更新使并发提交仅一方成功，另一方获得 HTTP 409 和最新进度。UI 暂停自动同步，要求明确选择。更新触发器在同一次数据库写入内保存旧数据，只保留最近 5 版。

远征普通移动后保存完整检查点。事件期间上传进入事件前的完整状态，避免恢复位置时重复结算事件奖励。离线生产根据该检查点的时间重新计算；原版探索中断不需要重新从家园出发。飞船实时躲避阶段不提供逐帧恢复，重新打开游戏会回到持久化的家园进度。

云存档可由部署者访问，不是加密保险箱。部署者应保留 D1 数据、遵守账号套餐额度，并在大版本迁移前备份；游戏内 JSON 导出适合个人另存。30 秒自动同步和最多 5 版历史用于进度恢复，不替代长期备份。

## 验证范围

`npm run verify` 创建临时本地 D1 并执行：生产人员守恒、建筑扣费、离线原料消耗与时间上限、晋级可达性、道路与辖地、难度、旧档迁移、格式校验、持续建设结局，以及真实 Workers API 的登录、恢复、账户隔离、并发版本与备份。Chromium 检查建设、晋级、刷新、远征与事件检查点、键盘和触屏操作、死亡救援、手机飞船与坠落、周目保留、注册和云存档冲突等主要流程。

这些检查覆盖关键状态转换，不等于人工从开场通关所有随机事件，也不包含实际 Cloudflare 账号的线上发布验证。
